# Deck SSH theme

## Design philosophy

**Cyberdeck utility, OLED dark first** (from the ui-ux-pro-max style "Dark Mode (OLED)", plus the hardware keyboards on cyberdeck builds: BlackBerry Q10/Q20, Hackberry Pi, uConsole).

1. **The keyboard is hardware.** It's always on screen and never hides, and the system IME never opens. Keycaps look physical: a skirt and a top face, a press that moves down, haptics.
2. **One grid.** Each keyboard row is 10 units wide and keys are 1, 1.5 or 5 units, so every key edge lines up on the same grid and the gaps match everywhere.
3. **Terminal first.** The terminal takes all the space the keyboard doesn't. There is no top bar. App controls live on the keyboard, and the drawers only show when you open them.
4. **Legible at a glance.** The terminal uses a monospace font (JetBrains Mono, ligatures off so the grid holds). Alt legends use the accent colour, and active modifiers use the primary colour.
5. **Themes are tokens.** Everything is drawn from the active `Palette`. Components never hard-code colours.

## Device skins (v2)

The whole screen is a device: chassis, top bezel with earpiece and LED, screen behind a bezel, a brand strip (logo plus name, glinting), and the deck keyboard. There is no app top bar and there are no drawers or settings screens. When no SSH tab is in front the screen is the local **console** (`ui/Console.kt`): everything is a typed command with a numbered menu (`/theme`, `/host`, `/setup`, `/logo`, `/brand`, `/colors`, `ssh user@host`). The strip keys (◂Hosts, Setup▸), the `≡` row, edge swipes and the status line just run those commands. Tabs show in a tmux-style line at the bottom of the screen; `[deck]` returns to the console.

- Skins are defined in `ui/Skins.kt`. The drawers and panels get a `Palette` derived from the skin (`Skin.ui`).
- The deck (brand strip plus keyboard) always takes at least 45% of the screen height, and the key height grows to make that happen.
- A Samsung-style number row (1–0, hold for ! @ # …) sits over the letters and the symbol layer. It is drawn short like the function row.
- Every press shows feedback: the key dips and scales to 94%, a glow ring spreads out from it, a character bubble pops up, and the phone vibrates.
- Each skin's logo glyph and brand name are set with `/logo` and `/brand` in the console.
- Screen colours either follow the skin (the default) or use one of the 87 palettes.

## Tokens

- **Palettes:** `ui/Themes.kt` (87 themes) is generated by `tools/gen-themes.js` from the shared pack (Kodi Control: Deck SSH set, Modern, Retro, Futuristic, Apple, your other apps, Open source, Steam, Community, Kodi skins, More retro). Each palette has `bg, surface, surface2, fg, muted, border, primary, onPrimary, accent, danger, warn` plus a dark flag. The pack's checks: text 7:1, muted 4.5:1, primary/accent 3:1.
- **Derived keyboard colours** (`Palette`): `deck`, `keyTop`, `keySkirt`, `modTop`, `fret`.
- **Terminal colours:** fg, bg and cursor come from fg, bg and primary (`applyTerminalColors`; they follow the skin by default). The ANSI 0–15 and 256-colour palettes keep the xterm defaults.
- **Spacing** (`Tokens`): s1 4, s2 8, s3 12, s4 16, s5 24 dp.
- **Radius:** rKey 7, rSm 8, rMd 12, rLg 16 dp.
- **Type:** caption 11, label 13, body 15, title 18 sp. Fonts: JetBrains Mono for the terminal and key legends, system sans for the rest of the UI.
- **Touch:** targets are at least 44 dp. Key height can be set from 36 to 64 dp (default 46).
- **Motion:** the keycap press is instant (no animation), the drawer uses Material's spring, and the caret blinks every 530 ms.

## Do

- Read colours from `LocalPalette.current` and sizes from `Tokens`.
- Keep every keyboard row at exactly 10 units.
- Take text input as a console prompt (`Console.ask`), so the built-in keyboard types into it.

## Don't

- Use `TextField`, `BasicTextField` or anything else that opens the system keyboard.
- Hard-code hex colours in components. The only exceptions are generated `Themes.kt` and the launcher icon.
- Hide or collapse the keyboard.
- Put ligatures or a proportional font in the terminal.
